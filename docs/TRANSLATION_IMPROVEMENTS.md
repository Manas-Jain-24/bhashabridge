# Translation improvement pass

The runtime now checks a SQLite `reviewed_translations` table first. Startup imports unambiguous examples from the project's curated 360-sentence teaching set, in both directions. It skips any source in the frozen translation test set and skips source sentences whose curated targets conflict. Repeated startups preserve local corrections. `scripts/add_reviewed_translation.py` is the manual correction path; it requires the `--reviewed` flag and refuses test-set sources. Model output is never silently promoted into this table.

For unmatched sentences, the configured IndicTrans2 model now uses the `IndicProcessor.preprocess_batch` and `postprocess_batch` contract around tokenization and generation. The old adapter manually prefixed language tags and skipped postprocessing. Upstream IndicTransToolkit needs a Cython build that failed on this Windows machine because Microsoft C++ Build Tools are absent. A local Hindi/Marathi-only processor applies the same language tags, Indic normalization, tokenization, script unification, and detokenization. It is used when upstream IndicTransToolkit is unavailable. The app still falls back to its rule engine if optional neural dependencies or model weights are unavailable. The unreviewed external parallel index has been removed from runtime exact lookup; it remains available as training/evaluation material after data cleaning.

Gemini is used for grammar explanations, not the translation itself. Its Python SDK is now in `requirements-core.txt`. The saved key should remain in `backend/.env`; do not paste it into source files.

The database improves exact known sentences. The neural path improves generalization only after its dependencies, weights, and inference are available. Neither guarantees correct translations. A clean, human-reviewed benchmark and further correction work are still needed before claiming reliable general translation.

Local verification on 24 October 2026: the existing SQLite database now has 660 reviewed entries. The saved Gemini key succeeded in a generation request and the explanation tutor returned valid JSON. IndicTrans2 loaded and translated an unseen Hindi sentence on the installed CPU-only PyTorch build; the first request took about 18 seconds through `/api/analyze`, including model loading and Gemini explanation. Five manual spot checks in both directions produced plausible outputs, but that sample is too small to establish quality. The full backend suite passed 96 tests, the frontend production build passed, and the leakage audit found zero held-out source overlap. The prior modular benchmark remains low (Hindi→Marathi BLEU 2.06; Marathi→Hindi BLEU 1.92) and its external references have alignment concerns. A full neural benchmark has not been run.
